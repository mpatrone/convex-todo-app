# Todo App

This is a simple Todo application built with [Convex](https://convex.dev) and [Convex Auth](https://labs.convex.dev/auth) V2. You can sign in with GitHub or Google (OAuth), or with a username and password.

## Features

- **View todos:** the app shows a list of your Todo items.
- **Create todos:** add new todos.
- **Edit todos:** click an existing todo to edit it.
- **Delete todos:** remove a todo with the trash icon.

## Getting Started

Start the development server (this runs both the Next.js frontend and the Convex backend):

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the app.
